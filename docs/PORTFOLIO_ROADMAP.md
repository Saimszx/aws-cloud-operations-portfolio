# Cloud Operations Portfolio Roadmap

## Career Direction

Primary target roles:

- Cloud Operations Engineer
- Junior Cloud Engineer
- Cloud Support Associate or Engineer
- Systems Administrator with cloud responsibilities
- Junior DevOps Engineer after building stronger automation experience

## Why This Portfolio Exists

Certifications validate knowledge, but employers also need evidence that a candidate can deploy, monitor, secure, troubleshoot, document, and remove cloud infrastructure. This portfolio is designed to provide that evidence.

AWS Skill Builder and Cloud Quest can supplement the portfolio with guided practice. Portfolio projects will still use independently written documentation and infrastructure code so that every claimed skill is supported by original, reproducible work.

## Phase 1 - Professional Foundation

- Learn and demonstrate Git and GitHub workflows
- Use clear repository names and commit messages
- Write recruiter-friendly and engineer-friendly documentation
- Establish secret-scanning and cost-safety habits
- Practice essential Linux administration

Completion evidence:

- Professional repository landing page
- Consistent project structure
- No secrets or generated state committed
- Small, reviewable commits

## Phase 2 - AWS Operations and Observability

Build an instrumented Linux workload and operate it through AWS-native services.

Completion evidence:

- Reproducible infrastructure as code
- Metrics, logs, dashboard, and alarms
- Secure administration through Systems Manager instead of public SSH
- A controlled incident simulation
- Incident timeline, root-cause analysis, and recovery evidence
- Verified teardown

## Phase 3 - Delivery, Reliability, and Recovery

- Deploy a static site through an automated pipeline
- Add HTTPS, caching, and availability controls
- Design and test backup and recovery procedures
- Document recovery objectives and tradeoffs

## Phase 4 - Serverless Operations and Cost Awareness

- Operate a small serverless application
- Add structured logging, metrics, tracing, and alarms
- Establish budgets and cost-review procedures
- Test common failures and document remediation

## Phase 5 - Career Packaging

- Add verified project links to the resume and LinkedIn
- Create concise interview stories using the STAR method
- Practice architecture explanations and troubleshooting scenarios
- Tailor applications to each job description

## Quality Gate for Every Project

A project is not marked complete until another person can understand the problem, reproduce the deployment, verify the result, and safely tear it down using the documentation in the repository.
